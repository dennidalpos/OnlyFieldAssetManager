# Native Windows qualification — RES-23

[Retained Italian source](windows-native-matrix.it.md)

Use an isolated synthetic profile/project. Never regenerate an EXE over personal data. Record build, window dimensions, theme, text scale, input/focus, screenshots and outcome. Full acceptance belongs to the tracker.

## Recorded scope

On 9 October 2026 a simple light-theme EXE at standard text scale passed save/failure/retry and undo in 11 editors: VLAN, subnet, WAN/VPN, extra fields, cables, logical interfaces, configurations, patching, power, PoE and badges. The historical matrix recorded 22 failure/retry saves and 11 undos; it did not cover all variants below.

On 11 October an isolated EXE imported the demo and showed sites, Logical, Devices, port card and project home. AUD-71 adjacent-VLAN-field layout was corrected/tested in Compose; its updated native rendering still needs inspection.

## Remaining native matrix

| Area | Required observation |
| --- | --- |
| Layout/focus | Themes, narrow/wide windows, enlarged text, dialogs/editors/AUD-71 and keyboard navigation |
| Network/cabling | Site/device scopes, IP/CIDR/VLAN, WAN/VPN devices, cable endpoints/media, complete patching, front/rear panel |
| Modules | Attachments in configuration, extra-field targets/types, UPS/PDU, PoE budgets/overrides, badges/documents |
| Long operations | Mouse/keyboard/focus, blocked edits, coherent draft/result during saves |
| Protection | Protected wizard failures, wrong-password retry, failed password change and recovery; user enters secrets privately |
| Merge/rejections | Associated data transfer, enlarged text, cycle/network reference rejection and correction without automatic retarget |
| PDF/printing | Unreadable-background errors, actual spooler failure, cancel and physical print |

JVM/Compose results do not complete RES-23. Preserve earlier reports and distinguish newly observed scenarios from completed base cases.
