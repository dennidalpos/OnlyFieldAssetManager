# Windows user guide

[Retained Italian source](windows.it.md)

The Windows 11 x64 application is portable. Keep the executable and data directory together; data contains projects, media and preferences. Do not regenerate the runtime over personal data. See [release instructions](../06-release-and-delivery.md).

## Work on a project

1. Start the EXE and open a local project or import an Android .ofam package.
2. Read the comparison before replacing a copy. For a merge, choose conflicts relative to the last-exchange base. Protected local copies may ask for their local password.
3. Navigate Map, Inventory, Cabling and Project. Technical destinations remain in their groups; empty optional areas appear in “Altri moduli”.
4. Wait for the save result. Busy state blocks input; failed saves preserve drafts for retry.
5. Export PDF/XLSX/Markdown in Documents; export .ofam for manual transfer.

Interrupted-save recovery can require the local protected-project password. Retain backups until recovery finishes. Physical printing and visual variants remain open in the [Windows matrix](../testing/windows-native-matrix.md).
