# Exchange and documents

[Retained Italian source](exchange-and-documents.it.md)

## Transfer a project

1. Export .ofam v1 in the source app, optionally with a package password.
2. Copy the file manually to the other device and import it. Review structural errors/documentary warnings before confirmation.
3. For an existing same-ID project, compare the copy and choose replacement or merge. Resolve merge conflicts individually.
4. Reopen after confirmation and inspect required attachments. A missing-file warning is not proof the file exists.

Android replacement follows received-package protection; merge keeps local protection. Exchange is not automatic synchronization. PDF/XLSX/Markdown exclude credentials; project-package credential handling follows the contract and explicit import choices.

## Generate documents

Choose site, floor, category and classification first. DocumentSelection applies filters across common formats. PDF renderers differ between platforms; inspect final plans/attachments. XLSX includes inventory and physical routes with free text preserved as text. Markdown escapes user content.

See [package/protection limits](../02-domain-data-contract.md) and [document sections](../03-export-and-documents.md).
